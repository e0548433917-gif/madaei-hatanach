## הערה על מה שלא כאן

**ספרי פליקס וספרי מקור סרוקים אחרים אינם בריפו הזה ולא יועלו אליו.** הם מוגנים בזכויות יוצרים (פרופ׳ יהודה פליקס נפטר בתשס״ה/2005 — ההגנה חלה עד 2075), והריפו ציבורי. הם משמשים כמקור ללימוד ולניסוח מחדש עם ייחוס, ונשארים מקומית אצל המפתח.

**חבילות `.otzplugin` של מפתחים אחרים** (ביוגרפיות, עיון ההלכה, יומא דהילולא וכו׳) גם הן אינן כאן — הן שימשו כחומר עזר לבדיקת API, וזמינות ממילא בחנות התוספים של אוצריא.
