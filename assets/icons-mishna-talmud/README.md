# איקונים לתוסף ״משנה ותלמוד״

התיקייה הזו מיועדת **לאיקונים של תוסף האחות המתוכנן — ״משנה ותלמוד״** (63 מסכתות: משנה, בבלי וירושלמי).
התוסף עצמו עוד לא נבנה; העבודה עליו מתחילה אחרי שתמונ״ך יגיע ל-3.0.0. האיקונים נאספים כאן מראש.

## איך מעלים לכאן

**דרך הדפדפן, בלי להתקין כלום:**

1. להיכנס לתיקייה הזו ב-GitHub.
2. **Add file** → **Upload files**.
3. לגרור את הקבצים, לכתוב שורת תיאור קצרה, ולחוץ **Commit changes**.

מי שאין לו הרשאת כתיבה — GitHub יציע אוטומטית לפתוח **Pull Request**, ובעל הריפו יאשר.

## מה המפרט

| | |
|---|---|
| פורמט | **PNG עם רקע שקוף** — לא JPG, ולא רקע לבן |
| גודל | **192×192** ריבועי (אפשר להעלות גם גדול יותר, נקטין) |
| שם הקובץ | באנגלית, אותיות קטנות, מקפים. למשל `berachot.png`, `bava-kama.png` |
| סגנון | תואם לאיקוני תמונ״ך — ספר פתוח בזהב, עם סמל הנושא במרכז. ראה [`assets/icons-store/`](../icons-store/) לדוגמאות |

⚠️ **הכי חשוב: רקע שקוף.** האיקונים מוצגים על רקע משתנה (ערכת נושא בהירה או כהה), ורקע לבן קבוע נראה כמו מלבן תקוע. אפשר לבדוק בקלות: לפתוח את ה-PNG על רקע כהה — אם רואים מסגרת לבנה, צריך לתקן.
