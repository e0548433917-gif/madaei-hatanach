# מדריך מקומות בתנ״ך — תוסף לאוצריא

תוסף המציג 248 מקומות מהתנ״ך, התלמוד והמדרש: ערים, ישובים, הרים, נהרות, עמקים, מדבריות, ארצות ותחנות מסעי בני ישראל — עם פסוקים, מקורות חז״ל, שיטות זיהוי, ומפה אינטראקטיבית.

## מבנה הקבצים

```
index.html                        נקודת הכניסה — מבנה הדף בלבד; טוען את כל השאר
manifest.json                     הגדרות התוסף לאוצריא (הרשאות, לשונית, גרסה)
css/
  app.css                         עיצוב האפליקציה (קלף, כרטיסים, מודאל, חיפוש)
  map.css                         עיצוב המפה: Leaflet + MarkerCluster (מוטמעים) + סגנון מותאם
js/
  vendor/leaflet.js               ספריית המפות Leaflet 1.9.4 (מוטמעת — אין תלות ברשת)
  vendor/leaflet.markercluster.js קיבוץ סמנים (אשכולות) 1.5.3
  map.js                          מודול המפה (ראו פירוט למטה)
  app.js                          לוגיקת האפליקציה: רינדור, חיפוש/סינון, מודאל, אינטגרציית אוצריא
data/
  places.js                       נתוני המקומות: CATS, ICONS, DATA (248 ערכים), EXTRA_TOWNS
  geo-basemap.js                  NE_DATA — שכבות המפה הווקטורית + תוויות בעברית
```

סדר טעינת הסקריפטים ב-index.html מחייב: vendor ← data ← map.js ← app.js (app.js קורא בסופו ל-`render()` ול-`initWorldMap()`).

## סכימת הנתונים (data/places.js)

כל ערך ב-`DATA`:

```js
{
  "name": "שם המקום בעברית",
  "cat": "cities|villages|mountains|water|valleys|deserts|lands|stations",
  "region": "תגית אזור (אופציונלי)",
  "aliases": ["שמות נוספים"],
  "methods": [{            // שיטת זיהוי אחת או יותר
    "label": "שם השיטה",
    "confidence": "ודאי|סביר|שנוי",
    "explanation": "הסבר",
    "modern": "תיאור המיקום בעולם המודרני",
    "mapQuery": "שאילתת חיפוש באנגלית (לקישור גוגל מפס)",
    "geo": [lat, lng, zoom]   // מיקום הסמן במפה + זום מומלץ
  }],
  "verses": [{"ref": "...", "text": "..."}],
  "midrash": [...], "academic": [...],
  "border": ..., "refuge": ..., "levite": ...   // שדות ייעודיים חלקיים
}
```

**עריכת מיקום**: משנים את `geo` בשיטה הרלוונטית. lat/lng בהחלטה עשרונית (WGS84), zoom בין 4 (יבשת) ל-14 (אתר). המיקומים הופקו בג'יאוקודינג (Nominatim/OSM) + ביקורת ידנית מול ויקיפדיה וידע גיאוגרפי-מקראי, ועברו סבב אימות נוסף; מקומות שזיהוים שנוי במחלוקת מסומנים ב-confidence.

## המפה (js/map.js)

שני מצבים:

1. **מפה מצוירת (ברירת מחדל, ללא אינטרנט)** — נתוני Natural Earth מוטמעים ב-`data/geo-basemap.js`:
   - `world/worldlines` — יבשות וגבולות לכל העולם (1:110M מפושט)
   - `region/regionlines` — המזרח התיכון ברזולוציה גבוהה (1:10M, פישוט 30%)
   - `rivers/lakes` — נהרות ואגמים (כולל הכנרת וים המלח)
   - `labels` — תוויות בעברית עם סף זום (`z`): מדינות, גופי מים, אזורים, ו-344 ערים (`kind:"city"` — נקודה + שם)
   - גבולות מצוירים כ-innerlines (גבולות משותפים בלבד) כדי שלא ייראה קו תפר בגבול אזור הפירוט
   - זום מרבי במצב זה: 12 (`MAP_MAX_ZOOM`)

2. **תצלום לוויין (רק כשיש אינטרנט)** — Sentinel-2 cloudless מ-EOX (tiles.maps.eox.at, ללא מפתח API):
   - בעליית המפה רץ `probeSatellite()` — טעינת אריח בדיקה עם timeout של 6 שניות
   - רק אם הצליח מופיע כפתור "🛰️ תצלום לוויין"; בלי אינטרנט המשתמש לא רואה את האפשרות כלל
   - במצב לוויין הזום המרבי עולה ל-17, ומצטרפת שכבת גבולות/שמות של EOX
   - **נטפרי**: אריחי הלוויין עשויים להופיע תחילה כ"נשלחה לבדיקה" עד אישור הדומיין `tiles.maps.eox.at`

תכונות נוספות: סמנים צבועים לפי קטגוריה (`CAT_COLORS`) עם אשכולות, פופאפ עם כפתור לכרטיס המלא, סנכרון דו-כיווני עם החיפוש והסינון (`updateMapFilter`), מיני-מפה בתוך המודאל לכל שיטת זיהוי (`renderMiniMap`), וכפתור "הצג במפה הראשית" (`focusOnMainMap`).

## עדכון נתוני המפה הווקטורית

הנתונים נבנו מ-Natural Earth (נחלת הכלל) עם mapshaper: קליפת bbox‏ 23–58 מזרח, 7–42.5 צפון, פישוט, והמרה ל-`const NE_DATA = {...}`. כדי לשנות (למשל להרחיב את האזור המפורט) יש לבנות מחדש את `data/geo-basemap.js` באותו פורמט.

## בדיקות

בדיקה מהירה בדפדפן: פותחים את `index.html` ישירות (file://). לבדיקת מצב "ללא אינטרנט" מנתקים רשת ומוודאים שהמפה הווקטורית עולה ושכפתור הלוויין לא מופיע. מחוץ לאוצריא הודעות ה-API (`Otzaria.call`) פשוט לא פעילות — זה תקין.
