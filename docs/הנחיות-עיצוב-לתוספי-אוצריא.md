# הנחיות עיצוב לתוספי אוצריא

מסמך זה מרכז את עקרונות העיצוב, הטוקנים, והרכיבים המשותפים לפיתוח תוספים לאוצריא בעלי **מראה תואם לאוצריא**.
המקורות הרשמיים עליהם מתבסס מסמך זה הם קוד המקור של אפליקציית אוצריא (Flutter/M3), קוד הלאנצ'ר הרשמי `Otzaria_Offline_update`, והתוסף לדוגמה `com.moshenahari.siduron`.

---

## 1. אילוצי חנות התוספים (״מראה תואם לאוצריא״)

תוספים המבקשים את התגית ״מראה תואם לאוצריא״ בחנות נבדקים אוטומטית בעת הפרסום. אי-עמידה בכללים מחזירה שגיאת HTTP 400 וחוסמת את שחרור התוסף:

1. **איסור על `#hex` או `rgb()` מחוץ ל-`:root`:**
   - כל צבעי הממשק בגוף ה-CSS חייבים להיקרא דרך משתנים: `var(--color-...)`.
   - שקיפויות וגוונים מחושבים באמצעות `color-mix`:
     `color-mix(in srgb, var(--color-primary) 12%, transparent)`
2. **איסור על `font-size` ב-`px`:**
   - יש להשתמש ב-`rem` או `em` (החריג היחיד המותר הוא כותרת הסרגל העליון למניעת חריגה).
3. **איסור על `border-radius` ב-`px`:**
   - יש להשתמש בטוקנים התקניים: `var(--radius-sm)`, `var(--radius-md)`, `var(--radius-lg)`, `var(--radius-pill)`.
4. **איסור על `font-family` קשיח:**
   - יש להשתמש ב-`var(--font-main)`.

## 3. רכיבי ממשק מובילים (UI Components)

### א. מתג גלולה (Toggle Switch — CustomSwitch)
מתג בסגנון Material 3 של אוצריא. מיושם כ-`<button type="button" role="switch">` עם תמיכה מלאה ב-RTL (באמצעות `inset-inline-start` ולא `left`):

```html
<button type="button" role="switch" aria-checked="true" class="switch" id="mySwitch"></button>
```

```css
.switch {
  box-sizing: border-box;
  inline-size: 46px;
  block-size: 26px;
  min-inline-size: 46px;
  min-block-size: 26px;
  border-radius: var(--radius-pill);
  border: 2px solid var(--color-outline);
  background: var(--color-surface-container-highest);
  position: relative;
  cursor: pointer;
  padding: 0;
  margin: 0;
  outline: none;
  transition: background var(--anim-medium), border-color var(--anim-medium);
}
.switch::after {
  content: "";
  position: absolute;
  top: 3px;
  inset-inline-start: 3px;
  inline-size: 16px;
  block-size: 16px;
  border-radius: 50%;
  background: var(--color-outline);
  transition: transform var(--anim-medium), inline-size var(--anim-medium),
              block-size var(--anim-medium), top var(--anim-medium), background var(--anim-medium);
}
.switch[aria-checked="true"] {
  background: var(--color-primary);
  border-color: var(--color-primary);
}
.switch[aria-checked="true"]::after {
  background: var(--color-on-primary);
  top: 1px;
  inline-size: 20px;
  block-size: 20px;
  transform: translateX(-20px); /* ב-RTL תנועה שמאלה להפעלה */
}
[dir="ltr"] .switch[aria-checked="true"]::after {
  transform: translateX(20px);
}
.switch:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;
}
```

### ב. פאנל הגדרות (Settings Card & Rows)
שכפול של `SettingsCard` ו-`ListTile` מאוצריא: מיכל עם כותרת חיצונית בצבע הראשי, שורות משטח נפרדות המופרדות ברווח שקוף (1.5px):

```html

  <div class="set-title">הגדרות תצוגה</div>
  <div class="settings-row toggle-row">
    <div>
      <div class="settings-row-title">הצגת תמונות</div>
      <div class="settings-row-subtitle">הצגת תמונות ממוזערות בכרטיסי הרשימה</div>
    </div>
    <button type="button" role="switch" aria-checked="true" class="switch"></button>
  </div>
</div>
```

### ג. דרופדאונים (AppDropdownField)
דרופדאון תקני של אוצריא: גובה 40px, צבע מיכל משני (`--color-secondary-container`), ורדיוס 8px (`var(--radius-sm)`):

```css
.dropdown-field select {
  min-block-size: 40px;
  border-radius: var(--radius-sm);
  background: var(--color-secondary-container);
  color: var(--color-on-secondary-container);
  border: 1px solid transparent;
  padding-inline: var(--space-lg) 34px;
  font-family: var(--font-main);
  outline: none;
}
.dropdown-field select:hover {
  background: color-mix(in srgb, var(--color-on-secondary-container) 8%, var(--color-secondary-container));
}
.dropdown-field select:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 1px;
}
```

### ה. כרטיסים (Cards)
רדיוס אחיד של 8px (`var(--radius-sm)`) לפי שפת אוצריא (במקום רדיוסים שונים כמו 3px או 16px):

```css
.card {
  border-radius: var(--radius-sm);
  background: var(--color-surface);
  border: 1px solid var(--color-outline);
  overflow: hidden;
  transition: transform var(--anim-fast), border-color var(--anim-fast);
}
.card:hover {
  border-color: var(--color-primary);
  transform: translateY(-2px);
}
```
