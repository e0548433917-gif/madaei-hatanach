הקשר וארכיטקטורה כלליים: [../למפתחים.md](../למפתחים.md).

## למה דווקא "סידורון"

התבקשנו להתאים את מראה התוסף לאוצריא. המקור הטוב ביותר שנמצא הוא התוסף
**"סידורון"** (`com.moshenahari.siduron`, v3.7.0) — הוא לא סתם "יפה", אלא
משכפל בקפידה את קומפוננטות ה-Flutter של אוצריא עצמה (`SettingsCard`,
`SegmentedSettingsTile`, `AppDropdownField`, `AppCard.section`), עם הערות
בקוד שמצביעות על השמות המקוריים. לכן: **מי שמעתיק מסידורון מתקרב לאוצריא,
לא לטעם של מישהו.**

איפה להשיג אותו: התוסף מותקן ברוב המכשירים, או להוריד מחנות התוספים ולחלץ
את `css/style.css` (זה קובץ אחד, ~16KB, כל המפרט שלמטה נגזר ממנו).

⚠️ **אין להעתיק את הקובץ שלו כמו שהוא.** סידורון משתמש בטוקנים משלו
(`--c-primary`), ואנחנו בשמות הרשמיים של אוצריא (`--color-primary`). מעתיקים
**את המידות והמבנה**, ומחליפים לטוקנים שלנו.

## 🔴 אילוץ חוסם — לקרוא לפני שנוגעים ב-CSS

לתוסף יש את התגית **"מראה תואם לאוצריא"** בחנות. גילינו בדרך הקשה
(גרסה 3.2.1) שברגע שיש את התגית, **אובדן תאימות מחזיר HTTP 400 וחוסם את
הפרסום כולו** — לא רק מוריד את התגית. כלומר CSS לא-תקין = אי אפשר לשחרר.

הכללים שהחנות אוכפת:

| אסור | מותר |
|---|---|
| `#hex` / `rgb()` / `rgba()` מחוץ ל-`:root` | `var(--color-*)`, ו-hex **בתוך** `:root` בלבד |
| `font-size` ב-`px` | `em` / `rem` |
| `border-radius` ב-`px` | `var(--radius-sm/md/lg/pill)` |
| `font-family` מפורש | `var(--font-main)` |

שני פתרונות שכבר עבדו אצלנו כשהיינו חייבים ערך גולמי:
* צבע שקוף על טוקן → `color-mix(in srgb, var(--color-x) 12%, transparent)`
  (הוולידטור פוסל `rgba(var(--x-rgb), .12)` כ"מקודד", אבל `color-mix` עובר).
* ערכים שחייבים להיות קבועים (למשל צבעי הדפסה שחור-על-לבן) → להגדיר אותם
  כטוקנים ב-`:root` (`--print-fg` וכו׳) ולהשתמש ב-`var()` בגוף הקובץ.

**היחיד שמותר לו `px` ב-`font-size` הוא כותרת הסרגל העליון** — זו דרישה
מפורשת ב-DESIGN_GUIDE (גודל הטקסט של הספר מגיע עד 36px ויפוצץ את הסרגל).

בדיקה מהירה לפני כל דחיפה:

```bash
node -e "const s=require('fs').readFileSync('shell/router.css','utf8').replace(/:root[^{]*\{[\s\S]*?\n\}/g,''); console.log('hex:',(s.match(/#[0-9a-fA-F]{3,8}\b/g)||[]).length,'px-font:',(s.match(/font-size:\s*[0-9.]+px/g)||[]).length)"
```
התוצאה התקינה: `hex: 0 px-font: 1` (ה-1 הוא כותרת הסרגל).

## מה כבר נעשה (פאנל ההגדרות בלבד)

* `.set-group` — כרטיס מעוגל, `--radius-lg`, כותרת ב-`--color-primary` מודגשת
* `.set-opts` / `.set-opt` — segmented control מחובר; הנבחר ב-`--color-secondary-container`
* `.dropdown-field` — דרופדאון מעוגל, חץ מצויר ב-CSS
* `.set-action` — כפתור פעולה בצורת גלולה
* הטוקנים `--color-secondary-container` / `--color-on-secondary-container` נוספו
  ל-`:root` (אור+כהה) ומוזרקים מערכת אוצריא ב-`shell/settings.js`

## מה נשאר — לפי סדר תועלת

### 1. 🔴 מתג toggle עגול — **הפער הגדול ביותר**

זה "הריבועים" שהתלוננו עליהם. כל תיבות הסימון בתוסף הן עדיין
`<input type="checkbox">` **ילידיות ומרובעות**: שני המתגים של הפרסום ליומן,
"תמונות בכרטיסים", וכל `.set-switch` אחר.

הצורה של אוצריא היא מתג גלולה 46×26 עם בוהן שמחליקה:

```css
.switch {
  width: 46px; height: 26px;
  border-radius: var(--radius-pill);
  border: 2px solid var(--color-outline);
  background: transparent;
  position: relative; cursor: pointer; flex: 0 0 auto;
  transition: background .2s, border-color .2s;
}
/* inset-inline-start ולא left: ב-RTL הבוהן מתחילה בימין (כבוי) ומחליקה שמאלה */
.switch::after {
  content: ""; position: absolute; top: 3px; inset-inline-start: 3px;
  width: 16px; height: 16px; border-radius: 50%;
  background: var(--color-outline); transition: .2s;
}
.switch.on { background: var(--color-primary); border-color: var(--color-primary); }
.switch.on::after { inset-inline-start: 23px; background: var(--color-on-primary); }
```

⚠️ זה `<button role="switch" aria-checked>` ולא `<input>`, ולכן **צריך גם
לשנות את ה-JS**: כל מקום שקורא `el.checked` / מאזין ל-`change` צריך לעבור
ל-`classList.contains('on')` ו-`click`. הקבצים: `shell/settings.js`
(`syncSettingsUI` + החיווט), ו-`index.html` (הסימון עצמו).
**להשאיר `aria-checked` מסונכרן** — אחרת קורא מסך לא יידע את המצב.

### 2. `.settings-row` — מבנה שורות בתוך הכרטיס

אצל סידורון כל שורה בכרטיס מופרדת בקו, ויש לה כותרת + תת-כותרת:

```css
.settings-card-body > .settings-row + .settings-row {
  border-top: 1.5px solid var(--color-surface-container-highest);
}
.settings-row { padding: 12px 16px; }
.settings-row.toggle-row { display: flex; align-items: center; justify-content: space-between; gap: 12px; }
.settings-row-title    { font-size: 1em; }
.settings-row-subtitle { font-size: .8em; color: var(--color-on-surface-dim); margin-top: 2px; }
```

אצלנו הכל שטוח בתוך `.set-group`. זה גם מקום טוב להזיז אליו את ההסברים
שיושבים היום כ-`.set-note` תלושים.

### 3. גובה אחיד 40px לפקדים

אצל סידורון כל `select` וכל כפתור segmented הוא בדיוק `height: 40px`.
אצלנו הגובה נגזר מ-padding ולכן משתנה בין פקד לפקד. שינוי קטן, אפקט גדול.

### 4. גוון רקע הדרופדאון

אצלו: `onSurface` בשקיפות 7% — אפרפר ניטרלי.
אצלנו: `--color-primary-subtle` — גוון זהב.
אם רוצים את המראה שלו: להוסיף טוקן
`--color-on-surface-subtle: color-mix(in srgb, var(--color-on-surface) 7%, transparent)`.

### 5. `.tool-btn` — כפתורי אייקון עגולים

```css
.tool-btn {
  width: 38px; height: 38px; border: none; border-radius: 50%;
  background: transparent; color: var(--color-on-surface-dim);
  display: inline-flex; align-items: center; justify-content: center;
  cursor: pointer; transition: background .15s;
}
.tool-btn:hover { background: var(--color-primary-subtle); color: var(--color-on-surface); }
```
מיועד ל-`#settingsCloseBtn` (היום ✕ חשוף), ולכפתורי הכלים בסרגלים.

## 🎯 החלק החשוב: להחיל על **כל** התוסף, לא רק על ההגדרות

עד היום העיצוב הזה נעצר בפאנל ההגדרות. המשימה האמיתית היא להפוך אותו
לשפה אחידה. איפה זה נוגע:

| אזור | קובץ | מה לעשות |
|---|---|---|
| בורר הספר | `index.html` + `.book-choice*` | האריחים כבר קרובים; ליישר גובה ורדיוס לתקן |
| פאנלים (`.panel-box`) | `router.css` | מבנה `settings-card`: כותרת ב-primary, שורות עם מפרידים |
| כרטיסי עמוד השער (`.card`) | `router.css` | לוודא רדיוס ומרווח אחידים עם הכרטיסים החדשים |
| האזור האישי | `personal.js` + `router.css` | הכי "ישן" בתוסף — טפסים וכפתורים בסגנון קודם |
| טפסי עריכה | `edit-forms.js` | `.f-input` / `.f-textarea` → גובה 40px ורדיוס תקני |
| שלושת מדריכי הכלים | `guides/talmud-tools/*` | פלטת קלף עצמאית **בכוונה** — ר׳ אזהרה למטה |

⚠️ **אל תאחיד את `guides/talmud-tools/`** (חולין, סוכה-לולב, מומים-בכורות).
הם עוצבו בכוונה בפלטת קלף משלהם, וזה חלק מהאופי שלהם. הם כבר עברו התאמה
טכנית לתגית (כל צבע גולמי הפך לטוקן ב-`:root` שלהם, `px` → `em`) **בלי
לשנות ולו פיקסל אחד במראה** — זו הדרך הנכונה: תאימות בלי שיטוח.

## סדר עבודה מומלץ

1. להוסיף את הטוקנים החסרים ל-`:root` (`--color-on-surface-subtle`)
2. `.switch` — CSS + החלפת ה-`<input>`-ים + עדכון ה-JS (הכי הרבה ערך)
3. `.settings-row` + גובה 40px — ליטוש הפאנל
4. `.tool-btn`
5. רק אז להתפשט החוצה לפאנלים ולאזור האישי

**אחרי כל שלב:** להריץ את בדיקת ה-hex/px למעלה, ולוודא שהפרסום לחנות עובר
עם `0 הערות עיצוב`.

## איך לבדוק בלי אוצריא

`_serve.ps1` מרים שרת מקומי, ואפשר לפתוח את `index.html` בדפדפן רגיל.
מה שדורש את ה-API של אוצריא לא יעבוד שם, אבל **כל העיצוב כן** — וזה מספיק
למשימה הזו. לבדוק בשתי ערכות (בהיר/כהה) ובשני רוחבים (13.3″ ומסך צר),
כי חלק מהכללים תלויים ב-`@media`.
