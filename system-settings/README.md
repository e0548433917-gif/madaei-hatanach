# הגדרות מערכת — תוסף לאוצריא

שליטה במחשב מתוך אוצריא, בממשק מגע גדול שמתאים לטאבלטים ולעמדות לימוד:

- **שמע** — עוצמה, השתקה, בחירת התקן פלט.
- **מסך** — בהירות (במחשבים ניידים/טאבלטים).
- **בלוטות׳** — הפעלה/כיבוי, מכשירים מוצמדים, חיפוש, צימוד והסרה.
- **רשת אלחוטית** — הפעלה/כיבוי, רשימת רשתות, התחברות (עם סיסמה) והתנתקות.
- **מצב נעילה** — הופך את המחשב לעמדת אוצריא בלבד: שורת המשימות מוסתרת, מקשי מעבר חסומים, ויציאה רק עם סיסמה. כולל קוד שחזור חד-פעמי.
- **מערכת** — פרטי המחשב והסוללה, נעילת מסך, שינה, הפעלה מחדש וכיבוי.

## דרישה: גשר אוצריא

התוסף מדבר עם שירות Windows קטן — **OtzariaBridge.exe** — שמאזין רק ל-127.0.0.1 (פורטים 47917–47921).
הורדה: <https://github.com/e0548433917-gif/madaei-hatanach/tree/כלי-מערכת (הגשר עדיין לא נכתב, ראו docs/STATUS.md)>

1. מפעילים את `OtzariaBridge.exe` פעם אחת — הוא מתקין את עצמו ועולה אוטומטית עם Windows.
2. פותחים את התוסף; החיבור מזוהה מעצמו (בדיקה חוזרת כל 10 שניות).

שחזור חירום ממצב נעילה: `OtzariaBridge.exe --unlock <קוד-שחזור>` מחלון פקודה, או Safe Mode.

## הרשאות

- `network.localhost` — פנייה לגשר המקומי בלבד (ללא אינטרנט).
- `app.open_url` — פתיחת קישור ההורדה של הגשר בדפדפן.

## פיתוח

פתיחת `index.html` בדפדפן רגיל (בלי אוצריא) מפעילה **מצב תצוגה מקדימה** עם גשר מדומה.
פרמטרים: `?offline=1` — מסך "הגשר אינו מחובר"; `?dark=1` — מצב כהה; `#kiosk` — פתיחה ישירה למקטע.

מבנה: `js/bridge.js` (סריקת פורטים וקריאות דרך `network.fetchStream`, וגשר מדומה), `js/ui.js` (ערכת נושא, דיאלוגים, הודעות), `js/app.js` (שלד וניווט), `js/sections/*.js` (מקטע לכל נושא).
